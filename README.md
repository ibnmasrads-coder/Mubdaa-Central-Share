# Mubdaa Central Share

Independent WordPress companion plugin for **MainWP Dashboard**, focused on desktop WhatsApp sharing immediately after publishing.

## Requirements
- WordPress 6.3+ and MainWP Dashboard installed on the **central dashboard only**.
- Desktop browsers: Chromium-based browser with image clipboard capability recommended.
- No WhatsApp API, WhatsApp Web automation, or changes to MainWP/Bridge files.

## UX contract
- Publishing completes normally; selected successful links are gathered from MainWP results.
- A lightweight share workspace appears above the native MainWP posting modal **after the final child-site result**.
- The source article image is fetched via an authenticated, same-origin WordPress endpoint; title is rendered on the PNG above the original photo. A failed fetch reports the exact HTTP status and offers retry.
- Sharing happens manually: paste the image into WhatsApp Web/Desktop **first**, then click **Copy all links** once; there is no splitting or truncation. If WhatsApp's image-caption limit is exceeded, paste the entire text as a subsequent text message (still one copy/paste).
- No permanent share history. One short-lived transient can hold source image metadata across MainWP's temporary-post deletion.
- Never claim WhatsApp messages were sent; the operator must confirm in WhatsApp.

## Project state
Development baseline. **Do not deploy to a live client dashboard until integration QA on the exact MainWP release**.

## v0.2.0-dev hotfix

- Fixed a critical source-image bug: `sanitize_key()` lowercased the mixed-case batch token generated by `wp_generate_password()`, invalidating the nonce and ephemeral image lookup.
- The browser fetches the source image using the same-origin, authenticated AJAX endpoint and shows diagnostic HTTP errors.
- The image proxy follows a limited number of WordPress-safe HTTP redirects.
- One-click clipboard text includes **every** selected site link regardless of character count.
- Removed the `(2/4)` split-caption button. The one-field preview is complete.
- Image retry is available after an HTTP/source failure.
- Added functional PHP image endpoint and ten-site long-message regression tests.

The real client image still needs confirmation on the live MainWP instance. The plugin has **not** been deployed and no existing MainWP/Bridge code is touched.
